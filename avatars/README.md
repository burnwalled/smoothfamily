# Smooth Family — preset avatars

12 flat geometric animal avatars in the app palette. SVG masters + 160px PNG.
Made for Smooth Family and licensed with it (AGPL-3.0). The app serves them from
frontend/public/avatars/; a member's avatar_key "preset:<name>" (e.g. "preset:fox")
picks one, next to uploading an own picture.
Names: bear, cat, dog, fox, frog, hedgehog, koala, lion, owl, panda, penguin, rabbit.
