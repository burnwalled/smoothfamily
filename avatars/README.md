# Smooth Family — preset avatars

12 flat geometric animal avatars in the app palette. SVG masters + 160px PNG.
Intended integration (see Phase P prompt): files served from
frontend/public/avatars/, user.avatar_key supports the "preset:<name>" scheme
(e.g. "preset:fox"), profile page shows a picker grid: presets + own upload.
Names: bear, cat, dog, fox, frog, hedgehog, koala, lion, owl, panda, penguin, rabbit.
