Private by design

Smooth Family runs on a computer in your home – a NAS, a Raspberry Pi or a small PC. The family's data stays there.

  • No accounts with us, no telemetry, no tracking, no fonts or scripts from other servers.
  • The only calls out are the ones you turn on – your calendar feeds, the weather, a recipe page.
  • Documents and passwords are encrypted with the family's key; backups are sealed with a key only you hold.
  • Children see what is meant for them; adults' own medicines, documents and passwords stay theirs.

Up and running in minutes

You need a computer that is always on, with Docker – or Docker Desktop on Windows or a Mac to try it.

Get it

Clone the repository on the computer that will be the family's server.

Install

The script writes the secrets, builds the app and prints a setup code.

Create the family

Open the app, enter the code, and a guide takes you through the server and the family.

# Linux, a Raspberry Pi or a Mac
git clone https://github.com/burnwalled/smoothfamily.git
cd smoothfamily
./scripts/install.sh            # Windows: .\scripts\install.ps1

Before you open it to the internet, read how to reach the server safely – home network, a VPN or HTTPS – and what each one costs. Several services it can fetch are Nordic (SMHI weather, Swedish electricity prices, school lunch); elsewhere those cards simply stay off.
